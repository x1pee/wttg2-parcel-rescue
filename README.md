# Parcel Rescue — Welcome to the Game II

Pick up stuck delivery boxes with F6 in Welcome to the Game II (WTTG2).

**Скачать:** [готовые файлы](https://github.com/x1pee/wttg2-parcel-rescue/releases/tag/v1.0.0).

F6 подбирает ближайшую уже доставленную посылку в радиусе 30 метров, включая коробки за забором. Используется штатный обработчик получения покупки. Предметы не создаются; посылки в полёте и ожидающие отправки пропускаются.

## Установка и использование

Скачайте ZIP из Releases. Закройте игру и скопируйте `WTTG2.ParcelRescue.dll` в `BepInEx/plugins`. Запустите игру снова. Для отката удалите эту DLL при закрытой игре.

Встаньте из-за компьютера, закройте меню, подойдите к доставке и нажмите F6. За одно нажатие подбирается одна коробка. Клавиша и радиус меняются в BepInEx/config/pmxp.wttg2.parcel-rescue.cfg. Не восстанавливает уже уничтоженные игрой коробки.

## Исходники и сборка

Сборка требует локальные игровые библиотеки и BepInEx 5.4.23.5; они не включены в репозиторий.

```powershell
.\build.ps1 -GamePath "D:\Games\Welcome to the Game II"
```

## Проверка

15 проверок в отдельном игровом процессе прошли: оригинальный подбор, увеличение инвентаря на один предмет, удаление коробки и отсутствие дублирования. Ручное нажатие F6 в обычном игровом сеансе отдельно не проверялось.

Проверено на Windows x64, Unity 2017.3. Для BepInEx-плагинов используется BepInEx 5.4.23.5. Совместимость с другими версиями игры не гарантируется.
